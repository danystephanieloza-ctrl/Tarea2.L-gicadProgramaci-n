# Generador seguro de Contraseñas #
Objetivo: Desarrollar un programa que permita generar contraseñas fuertes y seguras, ya sea de forma automática y aleatoria o mediante la participación del usuario en la creación de su propia contraseña, con el fin de proteger los datos personales en un entorno cada vez más digitalizado. 

# Funcionalidades del código #
Generación de contraseñas automáticas y aleatorias de contraseñas mediante el establecimiento de datos obligarotios que el sistema sigue para crear contraseñas seguras (criterios de configuracion establecidos como una longitud mínima, letras, numeros y simbolos y su aleatoriedad).
Participacion activa con el usuario, guiada por el sistema,  para escribir su propia contraseña segura. El sistema validará la contraseña del usuario siguiendo los criterios de configuracion establecidos. 
El sistema esta prepaarado para identificar caracteres faltantes en las contraseñas que escriba el usuario.
Opción a disposición del usuario para guardar o no guardar la contraseña creada o generada por el programa.

# Conocimientos de las 4 unidades del primer módulo aplicados al desarrollo del código #
Unidad 1: Se aplicó el análisis y comprensión del problema de la seguridad de contraseñas débiles y posibles riesgos de robo de informacion personal de los usuarios. Mediante digramas de arquitectura y de caso de uso, se planificó el desarrollo y estructura del programa, además de contar con los conocimientos previos para el uso de Python.  
Unidad 2: Se utilizó el manejo de datos mediante variables y tipos de datos (Enteros, string) para definir la longitud de la contraseña, los caracteres permitidos y las validaciones necesarias, siguiendo una estructura lógica del programa gracias al desarrollo de diagramas de flujo que guiaron el avance de la codificación en el Autónomo 2, además de investigaciones extra sobre códigos necesarios para el programa.
Unidad 3: Se aplicaron condicionales como “if” y bucles (while y for) para verificar si una contraseña cumple con los requisitos de seguridad caso contrario, se repetirá el proceso hasta que sea validada correctamente.
Unidad 4: Se usaron estructuras de datos como listas y funciones para organizar el código, mejorar su comprensión y a su vez, facilitar el mantenimiento del programa.
